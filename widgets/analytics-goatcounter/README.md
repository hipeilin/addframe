# GoatCounter analytics

Free, privacy-friendly, cookieless pageview analytics. One script tag,
no cookie-consent banner needed (it doesn't track individuals or use
cookies).

## Setup

1. Create a free account at [goatcounter.com](https://www.goatcounter.com/) —
   pick a site code, e.g. `yoursite` → `https://yoursite.goatcounter.com`.
2. Copy `head.html` into your page, anywhere (it's `async`). Replace
   `YOUR_ACCOUNT` in the `data-goatcounter` URL with your site code.
3. View stats at `https://YOUR_ACCOUNT.goatcounter.com`.

## Config

Just the one placeholder: `YOUR_ACCOUNT` in `head.html`.
